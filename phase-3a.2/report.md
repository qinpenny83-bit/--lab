F/G 本轮未降级为字段检查，做的是语义判定，且两面都验证到：

## 六、五个问题的正式回答

**Q1 第一轮 7 类缺陷是否在全新样本中再次出现？** 在原始候选中仍然出现（生成器天然犯这些错，22 次原始出现），但「缺陷泄漏到最终输出」这一意义上的复发未再出现。6 类可规则修复的缺陷（B/K/C/D/J 与 A 的来源缺漏）全部在源头层修复，H 的模板对被正确标记后阻断。

**Q2 频率是多少？** 原始出现频率：B×4、K×7、A×2、C×3、D×2、H×2、J×2。Leak-through 频率恒为 0。

**Q3 根因是否仍位于原来的生产层？** 是，错误仍产生于同一生成/采集层（这是生成器的固有属性），但每一项都被 Phase 3A.1 布置在**对应源头层**的护栏拦截（B/K 在 L1、A/D/K 在 L2、C 在 L3、J 在 L4、H 在 L5）。没有一例新鲜样本的错误逃过其指定源头层——证明 3A.1 的修复是根因级且可泛化，而非只对回归样本生效。

**Q4 是否出现第一轮没有的新型系统性缺陷？** 未出现「≥2 次且导致漏放」的新系统性缺陷。但有一个新发现的**非系统性**限制：E 语义门的两条启发式——`证据长度 <8 判空泛` 与 `具象征象仅认舌/脉/苔与病性词`——对「纯症状词汇、短句式」的证据产生保守性误判（`pa32-case-24`「入睡困难、多梦易醒」被误判为「缺乏具体征象」，`pa32-case-25`「胸闷如窒、痰多」因 7 字被 `长度<8` 误判为「空泛项」）。这两处误判方向是宁严勿松、且未改变任何终判（两样本均由 H 或 A/F/G 的主因隔离），但会增加人工复核噪声。

**Q5 当前生产管线是否具备进入 Phase 3B 的条件？** 有条件具备。管线已从「生成器自打分」变为「来源、事实、分类、教学、推理、安全、去重逐层约束，Gate 独立验收」，七类缺陷零漏放是硬证据。但按本轮边界，不自动进入 Phase 3B：3 个 conditional 需人工补 verified、E 语义词表需扩充、F/G 语义需人工复核，这三点应在 Phase 3B 启动前先闭合。

## 七、残余风险

1. 白名单覆盖缺口：`pa32-theory-19`「阴阳」原典（《素问·阴阳应象大论》「阴阳者，天地之道也」为真实原文）因未入白名单被保守降级为 `teaching_inference`，属「误降」，需人工恢复 verified。白名单仍只覆盖 13 个已知锚点，未知靠「未知即降级」兜底。
2. E 语义门启发式偏窄：`证据长度<8` 与 `舌/脉/苔词汇` 两条判据会导致短句式、纯症状证据被保守误判，属新发现但非系统性。
3. F/G 为弱语义判定，真实「是否推翻/是否回应反证」的分界仍须人工复核（与 Phase 3A.1 结论一致）。
4. J 红线清单覆盖 4 味马兜铃酸药材 + 3 个禁针穴，未穷尽全部高危对象：附子、生附子（四逆汤原方）有毒但不在「已禁用」清单内，毒性警示未纳入本轮 J 的红线触发。

## 八、是否进入下一阶段的建议

**建议：STOP，暂缓自动扩容，等待人工审核。** 核心目标已达成（证明根因修复且可泛化），但本轮存在 3 个 conditional、1 个 E 语义门偏窄限制、以及 F/G 需人工确认，符合 YELLOW 判定。人工审核若确认 3 个 conditional 补 verified、E 词表扩充、F/G 复核通过后，可放行进入 Phase 3B。在此之前不自动进入 Phase 3B、不自动扩容到 100/305、不自动写 Canonical Knowledge、不修改 Phase 2.5 封板 Schema、不因失败调低门禁阈值。
